# 题目 B2：正解与下料反解

## 运行

本题只使用 Python 标准库，不需要 `pip install`，也不需要 `requirements.txt`。

在本目录执行：

```powershell
python .\solve.py
```

Linux/WSL：

```bash
python3 ./solve.py
```

也可以在仓库根目录直接执行，入口会根据 `solve.py` 的位置自动找到公共实现：

```powershell
cd F:\实践考题
python .\题目B2\solve.py
```

公共数学实现位于上级目录 `../公共/robot_b_questions.py`，本目录的 `solve.py` 只负责选择并运行 B2。

## 计算链

```text
T_base_gripper = T_base_flange * T_flange_gripper
T_base_object = T_base_gripper * T_gripper_object
T_flange_object = T_flange_gripper * T_gripper_object
T_base_flange_target = T_base_object_target * inverse(T_flange_object)
```

`T_flange_object` 是固定工具链，程序将它作为缓存结果输出。最后使用目标法兰位姿回代工件目标位姿，并要求误差小于 `1e-9`。
