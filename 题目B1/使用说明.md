# 题目 B1：已知工件位姿反解法兰位姿

## 运行

本题只使用 Python 标准库，不需要 `pip install`，也不需要 `requirements.txt`。

在本目录执行：

```powershell
python .\solve.py
```

Linux/WSL：

```bash
python3 ./solve.py
```

也可以在仓库根目录直接执行，入口会根据 `solve.py` 的位置自动找到公共实现：

```powershell
cd F:\实践考题
python .\题目B1\solve.py
```

公共数学实现位于上级目录 `../公共/robot_b_questions.py`，本目录的 `solve.py` 只负责选择并运行 B1，避免复制一份变换算法。

## 计算链

题目假定工件坐标系与夹爪夹持中心重合，因此 `T_gripper_object = I`：

```text
T_base_flange = T_base_object * inverse(T_flange_gripper)
```

程序输出法兰平移、旋转矩阵、RPY-ZYX、四元数，以及矩阵路径和四元数路径的最大误差。验收阈值为 `1e-9`。

```text
RPY：  (180, 0, 15) deg
```
