# 题目 B3：Eye-to-hand 视觉引导定位

## 运行

本题只使用 Python 标准库，不需要 `pip install`，也不需要 `requirements.txt`。

在本目录执行：

```powershell
python .\solve.py
```

Linux/WSL：

```bash
python3 ./solve.py
```

也可以在仓库根目录直接执行，入口会根据 `solve.py` 的位置自动找到公共实现：

```powershell
cd F:\实践考题
python .\题目B3\solve.py
```

公共数学实现位于上级目录 `../公共/robot_b_questions.py`，本目录的 `solve.py` 只负责选择并运行 B3。

## 计算链

像素和深度先通过针孔模型反投影到相机系：

```text
x_camera = (u - cx) * Z_camera / fx
y_camera = (v - cy) * Z_camera / fy
z_camera = Z_camera
```

再使用固定的 eye-to-hand 外参转换到基座系。因为相机固定在机器人外部，相机相对基座的位姿不随机器人当前位姿变化，因此这一步不需要机器人当前关节或法兰位姿。

圆盘绕自身法向旋转对称，所以只需确定圆心位置和已知竖直法向，不需要视觉提供长轴角度。最后用 B1 的反解关系求抓取法兰目标位姿并回代验证。
