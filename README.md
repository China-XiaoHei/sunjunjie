# 机器人实践考题

本项目按题目拆分目录，每道题独立保存源码、运行说明和运行证据。

| 目录 | 题目内容 | 主要入口 |
|---|---|---|
| [`题目A1`](./题目A1/) | Three.js 三维场景与外部驱动 | `server.js`、`controller.py` |
| [`题目A2`](./题目A2/) | WSL 部署与 Windows 浏览器访问 | `使用说明.md` |
| [`题目A3`](./题目A3/) | Go TCP 多客户端聊天程序 | `cmd/server`、`cmd/client` |
| [`题目B1`](./题目B1/) | 已知工件位姿反解法兰位姿 | `solve.py` |
| [`题目B2`](./题目B2/) | 正解与下料法兰位姿反解 | `solve.py` |
| [`题目B3`](./题目B3/) | Eye-to-hand 视觉定位 | `solve.py` |
| [`公共`](./公共/) | B1-B3 共用数学实现、测试和运行报告 | `robot_b_questions.py` |

根目录文件：

- `机器人实践考题.pdf`：原题。
- `机器人实践考题_解题方案.md`：总体解题方案和验收清单。
- `项目目录说明.md`：目录职责与整理约定。

每道题的详细运行步骤以对应目录中的 `使用说明.md` 为准。

依赖说明：

- Python 代码全部使用标准库，不需要执行 `pip install`，因此没有额外的 `requirements.txt`。
- A1/A2 的网页部分使用 Node.js 和本地 npm 依赖，首次运行 A1 时在 `题目A1` 目录执行 `npm install`。
- A3 使用 Go 标准库，模块文件位于 `题目A3/go.mod`。
